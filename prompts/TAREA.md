
# Tarea: Mi prompt profesional

## Funcionalidad elegida

Programa en Java para registrar, consultar, modificar y eliminar productos de una tienda.

## Version 1: prompt basico

```text
Crea un programa para gestionar productos.
```

Esta primera version es muy general y no indica el lenguaje de programacion ni las funciones que debe realizar el sistema.

## Version 2

```text
Actua como desarrollador Java. Crea un programa en Java para gestionar los productos de una tienda, usando una clase Producto con los atributos codigo, nombre, precio y stock.
```

Se agrego el rol, el lenguaje de programacion y los datos que debe contener la clase. La respuesta es mas especifica y relacionada con la necesidad.

## Version 3: prompt final

```text
Actua como desarrollador Java. Crea un programa en Java para gestionar los productos de una tienda mediante una clase Producto con los atributos codigo, nombre, precio y stock. Incluye las operaciones para registrar, consultar, modificar y eliminar productos. Usa este estilo para los metodos: getPrecio(), setPrecio(double precio). Explica primero la estructura de la clase y luego presenta el codigo Java. No utilices librerias externas.
```

Se agregaron las operaciones necesarias, un ejemplo del estilo de los metodos, el formato de respuesta y una restriccion. El prompt permite obtener una respuesta mas completa y organizada.

## Componentes del prompt final

| Componente | Texto utilizado |
|---|---|
| Rol | Actua como desarrollador Java. |
| Instruccion | Crea un programa en Java para gestionar los productos de una tienda. |
| Contexto | Mediante una clase Producto con los atributos codigo, nombre, precio y stock. |
| Ejemplo | getPrecio(), setPrecio(double precio). |
| Formato | Explica primero la estructura de la clase y luego presenta el codigo Java. |
| Restriccion | No utilices librerias externas. |

## Evaluacion del resultado

| Criterio | Cumple |
|---|---|
| Define claramente el rol de la IA | Si |
| Explica la funcionalidad solicitada | Si |
| Incluye los atributos de la clase | Si |
| Presenta un ejemplo de los metodos | Si |
| Indica el formato de la respuesta | Si |
| Incluye una restriccion | Si |

## Errores que evite

- Ser demasiado general: indique claramente que programa necesitaba.
- No proporcionar contexto: especifique los atributos y las operaciones de los productos.
- No indicar el formato: solicite explicar primero la estructura y despues presentar el codigo.
- Mezclar demasiadas instrucciones: organice las indicaciones de forma clara.
